# Security policy

Không mở issue công khai cho lỗ hổng hoặc dữ liệu nhạy cảm. Hãy dùng GitHub private vulnerability reporting nếu được bật. Repo demo không chứa secret thật; cấu hình local dùng `.env` và production phải dùng secret manager. Không ghi PII của người học vào log, metric label hoặc model artifact.
