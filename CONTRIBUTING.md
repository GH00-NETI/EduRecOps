# Contributing

1. Tạo branch ngắn theo mục tiêu.
2. Thêm hoặc cập nhật test cho thay đổi policy/data contract.
3. Chạy `make validate` trước khi mở pull request.
4. Không commit dataset, secret, model artifact lớn hoặc thông tin người học nhận dạng được.
5. Pull request phải mô tả tác động đến offline metrics, online SLO và backward compatibility.
